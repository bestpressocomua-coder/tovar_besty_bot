# Bestpresso · Заявки — Telegram-бот

Бот для формування замовлень і інвентаризацій у форматі бланків 1С (xlsx),
які надсилаються вкладенням у відділ обліку.

## Що вже реалізовано (каркас)
- Флоу: **Замовлення** / **Інвентаризація**
- Замовлення: Регіон → каталог (на весь філіал); для **Львова**: Регіон → локація → каталог
- Інвентаризація: Регіон → (Львів: підлокація) → локація → **автомат** → каталог (номенклатура типу автомата)
- Автопідстановка **замовника** (з таблиці за Telegram-ID) і **дати**
- Генерація xlsx-бланків (замовлення / інвентаризація) і надсилання отримувачу

## Структура
```
bot.py           — логіка бота (aiogram v3, FSM)
data_loader.py   — завантаження довідників із CSV
blanks.py        — генерація xlsx-бланків (openpyxl)
config.py        — налаштування (токен, отримувачі, шляхи)
data/
  catalog.csv    — номенклатура: group, subcat, name, type, unit, articul
  locations.csv  — локації: region, sublocation, address, inv, atype, model
  employees.csv  — замовники: telegram_id, name, role
```

## Запуск
1. `pip install -r requirements.txt`
2. Заповнити `config.py`:
   - `BOT_TOKEN` — токен від @BotFather
   - `RECIPIENT_ORDERS`, `RECIPIENT_INVENTORY` — chat_id отримувачів
3. `python bot.py`

## Що потрібно від відділу обліку
- **Експорт номенклатури з 1С з колонками `unit` (од. виміру) та `articul`** — зараз порожні
- **База замовників** (`employees.csv`): реальні Telegram-ID співробітників
- **Отримувачі** файлів (chat_id) для замовлень та інвентаризації
- Довідники ведуться вручну (можна тримати в Google Sheets і експортувати в CSV);
  після оновлення — команда `/reload` у боті

## Оновлення каталогу/локацій
Редагуєте `catalog.csv` / `locations.csv` (додали товар/автомат — додали рядок).
Код не змінюється.
